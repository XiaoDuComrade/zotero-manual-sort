# Manual Sort for Zotero 9

在 Zotero 9 中手动排列左侧分类，以及普通分类中的条目。

## 使用

1. 安装 `zotero-manual-sort-0.2.0.xpi` 并重启 Zotero。
2. 在左侧分类树中拖动分类：放到同级分类的上三分之一或下三分之一，可调整前后顺序。
3. 打开一个普通分类，在中间条目列表中拖动一个或多个条目，放到目标条目的上半部或下半部。
4. 两类顺序都会在重新打开 Zotero 后恢复。

左侧分类排序支持：

- “我的文库”下的顶层分类；
- 同一父分类下的子分类；
- 父分类连同其展开的全部后代一起移动。

拖到分类行的中央区域时，插件不接管操作，仍使用 Zotero 原生的“移入该分类、改变父级”功能。为避免含义不清，插件不允许直接跨父级调整前后顺序。

点击标题、作者、年份等表头时，列表会临时恢复为相应字段排序。再次拖动条目后，当前列表顺序会成为新的手动顺序。

分类右键菜单额外提供：

- `按手动顺序显示`
- `将当前显示顺序保存为手动顺序`

第二个命令适合先按年份、标题等字段排好，再将该顺序作为手动排序的起点。

## 安全限制

为避免意外覆盖不可见条目的位置，以下状态不会接管手动拖放：

- “我的文库”、保存的搜索、回收站等非普通分类；
- 快速搜索框中存在过滤条件；
- 已启用递归显示子分类；
- 当前分类不可编辑；
- 拖动的是父条目下面的附件或笔记。

条目手动顺序保存在 Zotero 数据库已有的 `collectionItems.orderIndex` 字段中；左侧分类手动顺序保存在插件的本机首选项中。插件不修改分类名称、题名、Extra、标签或附件。

两类手动顺序目前都应视为本机设置：Zotero 官方同步协议不保证跨设备同步 `orderIndex`，插件首选项也不会随文库同步，因此不同电脑上的顺序可能不同。左侧分类树处于筛选状态或分类不可编辑时，插件会保留 Zotero 原生拖放行为。
