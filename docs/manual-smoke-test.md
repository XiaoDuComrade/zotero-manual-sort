# Zotero 9 手动验收

1. 使用独立 Zotero 测试配置安装生成的 XPI。
2. 新建分类，加入 A、B、C、D 四个顶层条目。
3. 将 C 拖到 A 上半部，确认顺序变为 C、A、B、D。
4. 多选 A、B，拖到 D 下半部，确认多选内部顺序不变。
5. 展开带附件的父条目并移动父条目，确认附件跟随父条目移动。
6. 重启 Zotero，确认分类顺序保留。
7. 点击“标题”表头，确认可以临时按标题排序；随后拖动一次，确认重新进入手动顺序。
8. 先按年份排序，再在分类右键菜单选择“将当前显示顺序保存为手动顺序”，确认重启后保留。
9. 在快速搜索框输入文字，确认插件不接管拖放。
10. 启用递归显示子分类，确认插件不接管拖放。
11. 把条目拖到另一个分类，确认 Zotero 原生跨分类拖放仍然正常。
